
# План изменений (один проход, чтобы уложиться в 5 кредитов)

Цель — собрать все запросы в один аккуратный набор правок без раздувания приложения.

## 1. Навигация и иерархия
- **Трекер становится главным экраном.** Корневой редирект `/` и после онбординга → `/tracker`. В `TabBar` Трекер первый и по центру; "Today" (планер) — вторая вкладка.
- **Кнопка «Назад»** в `DayView` (просмотр завтрашнего/запланированного дня): добавить sticky-хедер с `←` и подписью даты, всегда возвращает на `Today`.
- **Календарик-индикатор**: в шапке Today/History показывать мини-полоску дат (7 дней). На датах, где есть `plan` с блоками, — точка/галочка. Тап → `DayView` этой даты. Это и есть «визуально показывать что день запланирован».

## 2. Чистка Pro-упоминаний
- Удалить `ProBadge` из шапки Today.
- В `Settings` свернуть `ProCard` в одну тонкую строку «План: Free / Pro» с кнопкой `›` (открывает UpgradeSheet). Никаких списков фич и квот на главном экране настроек.
- Из `TodayInsight` и баннеров убрать апселлы, оставить только мягкий лимит при попытке `Generate plan`.
- Удалить **Rescue my day** полностью (компонент `PlanDriftNudge` + триггеры + edge-функция `micro-reschedule-options` снимаем с UI, файлы оставим, чтобы не тянуть миграции).
- Удалить **One thing mode** из каталога Pro и любых упоминаний (это был отдельный фуллскрин-фокус для одной задачи — пользователь не понял идею, выпиливаем).

## 3. AI: парсинг времени и параллельные задачи
В `supabase/functions/generate-plan/index.ts`:
- Усилить системный промпт: если в свободном вводе есть явное время («в 15:00 звонок», «3 часа гулять с сыном») — **жёстко закрепить** `start_time` без сдвигов.
- Поддержать **параллельные блоки**: новое поле `parallel_with` (id/индекс) в JSON-схеме. Когда два дела пересекаются по времени и это указано пользователем как одновременное (например «гуляю с сыном» + «звонок 15:19») — AI помечает второй блок `parallel: true`, мы рендерим его как «вложенный» бейдж справа от основного, а не как конфликт.
- В UI `SortableBlock`: если `parallel: true` — показываем компактную пилюлю «+ параллельно: Звонок 15:19» внутри родительского блока.

## 4. Задачи без таймера → дедлайн + уведомление
- Новое поле блока `mode: "timer" | "deadline"` (по умолчанию `deadline`).
- В `deadline`-режиме нет обратного отсчёта — только время начала и конца. За 5 минут до конца — локальное уведомление «время подходит к концу» (через уже существующий `blockReminders.ts`, добавить `endLeadMin`).
- Кнопка «Done» остаётся; кнопки «Start timer» нет в deadline-режиме.
- В Focus-экране: deadline-вид показывает большое «осталось 12 мин» вместо таймера.

## 5. Персонализация AI
В `Settings` → блок «AI tone» расширяем до **AI behavior**:
- Тон (как сейчас).
- Слайдер «Подробность планов»: краткие / средние / детальные.
- Чекбоксы: «Учитывать энергию по времени дня», «Добавлять перерывы автоматически», «Группировать похожие задачи».
- Текстовое поле «Что AI должен помнить обо мне» (передаётся в системный промпт всех функций).
Эти настройки сохраняются в `profiles` (новые колонки: `ai_verbosity`, `ai_auto_breaks`, `ai_group_similar`, `ai_memory`).

## 6. Минимализм / меньше скролла
- `Today`: убрать TodayInsight-карточку, KpiCard-сетку свернуть в одну компактную строку под датой. Pro-баннеры — out.
- `Settings`: секции «Advanced» и «More» сворачиваем по умолчанию (уже частично есть). «Connections» переносим в Advanced.
- Все `app-card py-5` → `py-3` на мобиле, `py-4` на md+. Заголовки секций — `text-[10px]` uppercase, межсекционный отступ `mt-6` вместо `mt-8`.
- Hero-glass на Today сжать: убрать большой H1, оставить дату + статус одной строкой.

## 7. Триал — мелочь
Оставляем как есть (5 дней пожизненно), просто перестаём его навязчиво показывать.
